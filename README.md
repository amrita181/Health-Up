# Healthchef – Health & Fitness App

Live demo: https://health-up-beta.vercel.app

React + Vite frontend and Spring Boot backend.

## Features
- BMI calculation with a personalized diet and workout plan
- (add other features that work)

## Tech stack
React, Vite, Tailwind CSS, Spring Boot, Java, SQLite, Docker
Deployed on Vercel (frontend) and Render (backend)

## Run locally
Backend: cd backend, then .\mvnw spring-boot:run
Frontend: cd frontend, then npm install, then npm run dev
